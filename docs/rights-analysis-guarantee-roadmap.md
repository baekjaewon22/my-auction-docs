# 권리분석 보증서 후속 논의 메모

최종 업데이트: 2026-08-21

## 사용자가 확정한 전제

- 첫 번째 장은 현재 보증서 폼을 거의 그대로 유지한다.
- 2번째 장부터 물건별 특이사항과 위험요소를 체크하는 현재 방식을 발전시킨다.
- 지금은 기획만 보관하고 바로 구현하지 않는다.

## 현재 출력 구조

- 1페이지: 작성일, 사건번호, 법원, 말소기준권리, 임차권리, 경매취하/무잉여 가능성
- 2페이지 이후: 특이사항 요약
- 체납관리비에 대한 공통 법률 설명 페이지가 있음
- PPT 템플릿은 4개 슬라이드이며 현재 4번째 슬라이드는 빈 페이지로 확인됨
- 특이사항 문구는 길이가 늘어나면 슬라이드를 복제해 나누지만, 1페이지의 긴 문구는 독립적인 넘침 방지가 부족함

## 2페이지 이후 추천 구조

### 1. 특이사항 종합 체크표

각 항목은 `이상 없음`, `확인 필요`, `위험`, `미확인`으로 구분한다.

- 권리관계: 선순위 전세권, 가처분, 가등기, 법정지상권, 유치권, 토지별도등기, 대지권 미등기, 공유지분, 중복·병합 사건
- 임차·점유: 대항력, 배당요구, 보증금 인수, 소유자와의 관계, 전입일·확정일, 점유자 미상, 문서 간 불일치, 명도 난이도
- 물건 위험: 위반건축물, 제시외 건물, 토지·건물 일괄매각, 농지취득자격증명, 재개발·재건축, 맹지, 경계 문제, 현황 변경
- 입찰·비용: 체납관리비, 임차보증금 인수, 명도비용, 부대비용, 무잉여, 취하, 매각불허가, 입찰보증금 특례

체크표에는 상태만 넣고 긴 설명은 담지 않는다.

### 2. 위험·확인 필요 항목 상세

체크표에서 `위험` 또는 `확인 필요`로 판정된 항목만 다음 형식으로 자동 출력한다.

1. 확인 내용
2. 판단 근거
3. 예상 영향
4. 입찰 전 조치사항

각 항목에 근거 문서(등기부, 매각물건명세서, 현황조사서, 감정평가서)를 함께 표시한다.

### 3. 인수·추가 비용 요약

- 확정된 인수금액
- 추정 인수금액
- 확인이 필요한 금액
- 임차보증금, 공용부분 관리비, 명도 관련 비용을 구분

### 4. 근거자료·검수 내역

- 각 원본 문서의 발급일시/확인일시
- 자동 추출 성공 여부
- 담당자 수동 검수 여부
- 법무법인 검토 여부와 검토 범위
- 발급번호, 문서 버전, QR 진위 확인

## 출력 방식 개선 원칙

- 내용이 길어져도 글자를 과도하게 줄이지 않고 상세 페이지를 추가한다.
- 위험은 빨간색, 확인 필요는 주황색, 이상 없음은 녹색, 미확인은 회색으로 구분한다.
- `담당자 확인 필요`가 남아 있는 경우 정식 보증서가 아닌 `검토용 초안` 워터마크를 사용하는 방식을 검토한다.
- 모든 페이지에 사건번호, 발급번호, 페이지 번호를 표시한다.
- 빈 4번째 슬라이드를 제거한다.
- 체납관리비 공통 설명은 개별 물건에 필요할 때만 출력하거나 선택형 부록으로 분리한다.
- 누락된 필수 변수와 텍스트 넘침·겹침·빈 페이지를 발급 전 자동 검사한다.

## 유료화 전 별도 검토 사항

- `보증서`라는 상품명을 유지하려면 보증 대상, 유효기간, 한도, 제외사유, 재발급, 오류 및 손해 접수 절차를 약관과 문서에 명확히 정한다.
- 실제 손해보전을 제공하지 않는다면 `권리분석 확인서` 또는 `입찰 권리분석 보고서`로의 명칭 변경도 검토한다.
- 자동 분석, 사내 담당자 검수, 법무법인 명승의 검토 범위를 구분하고 실제 운영 범위와 출력물 표시를 일치시킨다.
- 체납관리비는 전체 미납액이 자동으로 인수된다는 표현을 피하고, 공용부분·전유부분·연체료를 구분해 표시하는 방식을 법률 검토한다.

## 다음 논의 시 시작점

1. 현재 `certificate.pptx`의 1페이지는 유지한다.
2. 2페이지 특이사항 체크표의 실제 항목과 표현 순서를 확정한다.
3. 각 체크 항목을 현재 파싱 데이터로 자동 판정할 수 있는지 매핑한다.
4. 자동 판정할 수 없는 항목은 담당자 수동 체크 입력으로 구성한다.
5. 위험 항목만 상세 페이지로 늘어나는 동적 PPT/PDF 구성을 설계한다.
