# 전자명함 — 로컬 구현

관리: `/business-card` (마이페이지 → 전자명함, 로그인한 재직 인원)
공개: `/card/:slug` (로그인·오피스 레이아웃 없는 별도 HTML 페이지)

## 디자인 및 선택 항목

- 관리 화면은 768px 이하에서 제목/저장 도구 다음에 고객 전달 영역을 배치하고, 통계 → 편집 → 미리보기 순으로 표시한다.
- 프로필 사진은 일반 사진 선택과 `capture="user"` 촬영 입력을 분리한다. 권한 UI/촬영 지원은 OS·브라우저가 제어하며, 앱 내 브라우저에서 지원하지 않으면 외부 브라우저를 안내한다. 지원 업로드 형식은 JPG/PNG/WebP이다.
- 새 명함의 소개/약력은 공통 경매 상담 안내 문구로 시작한다. 실제 연차·자격·수상·성과를 임의로 생성하지 않는다. 기존 작성 문구(빈 값 포함)는 유지하며, 관리자가 기본문구 채우기를 선택하면 편집 상태에서 교체한다.

- 모바일 상담 바는 두 칸/버튼 높이 44px, 줄바꿈 금지, 화면 폭에 따라 12~15px 글꼴을 사용한다. 하단 안전영역과 본문 하단 여백을 확보하고 이름 박스보다 높은 표시 순서를 갖는다.
- 사진 영역 최소 높이는 620px이며 이름 박스는 내용에 맞춰 높이를 정한다(기존 사진 높이 1/3 최소 높이 제거). 이메일 항목명은 줄바꿈하지 않으며 긴 주소는 오른쪽 영역 안에서만 줄바꿈한다.
- 인스타그램 그라데이션/네이버 blog 말풍선 로고는 인라인 SVG로 표시한다. 연락처 저장은 기존 VCF 방식이며 기기별 추가/가져오기 안내를 제공한다. 무확인 자동 전화번호부 등록을 제공하지 않는다.

- 최하단 회사소개는 여백이 있는 최대 560px 카드형 슬라이드다. 좌우 버튼으로 두 페이지를 순환하며 자동 전환은 없다. 고정 높이·내부 스크롤 없이 전체 디자인을 보여준다. 기본 문구는 공통이며 관리 화면에서 영역 전체를 숨기거나 커스텀 이미지 한 장으로 대체할 수 있다.
- 첫 페이지는 원본의 원형 배치를 유지하며 비율 좌표와 컨테이너 기준 글꼴 크기로 전체를 함께 축소한다. 모바일에서 2열로 재배치하지 않는다. 원본의 4·7번에만 의도적인 줄바꿈을 유지한다. 선택한 항목의 설명 하나만 도형 아래에 펼치며 같은 항목을 다시 누르거나 닫기를 누르면 접힌다.
- 두 번째 페이지는 사용자가 제공한 `KakaoTalk_20261023_115707022.png` 원본을 `public/brand/company-consulting-fees.png`로 복사해 이미지 그대로 표시한다. 기본·커스텀 이미지 모두 클릭하면 동일 페이지의 확대 팝업으로 열리고 닫기/ESC/바깥 클릭으로 닫힌다. 수수료 HTML 재구성은 제거했다. 새 클릭 통계는 추가하지 않는다.
- `companyHidden=yes`는 전체 회사소개 영역을 숨긴다. `companyImage`는 브라우저에서 최대 1600px JPEG로 변환한 커스텀 이미지로, 설정하면 기본 소개를 대체한다. 각 이미지 상한은 700,000자이며 프로필 이미지와 함께 저장하기 위해 전체 요청 상한은 1,500,000자로 제한한다. 두 항목 모두 기존 초안/공개 스냅샷 흐름을 따른다.

- 이름 박스 불투명도 80%, 색상 5종(블랙·블루·네이비·실버·그린). 기존 오렌지는 네이비로 대체한다.
- SNS는 Instagram·네이버 블로그·YouTube 중 선택 후 + 버튼으로 각각 최대 1개 추가한다. 미입력/삭제한 항목은 공개 페이지에서 숨긴다. 하단 우측에 로고만 표시하며 원본 주소는 표시하지 않는다. 서비스명은 접근성 레이블과 툴팁으로 제공한다. 영역 높이는 기본 52px이며 클릭 영역은 44px을 유지한다.
- 공개 명함 하단의 이름·익명 집계 안내 문구는 표시하지 않는다. 집계 기능과 관리 화면의 지표 설명은 유지한다.
- 영상 사용을 켜고 유튜브 영상 주소를 입력하면 사진과 소개 문구 사이에 폭 100%의 단일 플레이어를 표시한다. 미사용 시 영역 자체를 생략한다. 미리보기에서는 위치 안내를 표시하고 실제 재생은 공개 명함에서 확인한다.
- 영상은 [YouTube 공식 임베드 방식](https://developers.google.com/youtube/player_parameters)을 사용한다. 영상 소유자의 공개·임베드 허용 여부에 따라 재생되지 않을 수 있다.
- SNS 클릭과 영상 재생 이벤트는 별도로 수집하지 않는다.
- 관리 화면을 조회하거나 저장하면 8자리 짧은 주소를 생성해 복사 주소로 제공한다. `business_card_short_links` 별도 테이블의 고유 제약과 충돌 재시도로 연결한다. 기존 UUID 주소는 유지하며 두 주소의 이벤트는 기존 내부 slug로 통합한다.

- 초안 저장과 공개 내용을 분리한다. `공개 내용 적용` 시 공개 스냅샷을 갱신한다.
- 비공개/미승인/퇴사자 명함은 공개 페이지·사진·연락처에서 모두 404 처리한다.
- 관리 API는 기본적으로 로그인 사용자 ID를 사용한다. `master`만 `user_id`로 다른 담당자의 명함·통계를 조회하고 수정할 수 있다. 대표/일반관리자 등 나머지 역할은 타인 ID 요청 시 403이다. 담당자 검색 목록 API도 master 전용이다.
- 마스터의 삭제는 확인창을 거쳐 해당 명함·이미지·짧은 링크·방문 이벤트를 제거하며 직원 계정은 삭제하지 않는다. 삭제는 복구할 수 없다. 퇴사자 명함 정리는 가능하지만 퇴사자/미승인 명함의 공개는 차단한다.
- 저장된 명함은 조회 모드로 열리고 수정 버튼으로 편집을 시작한다. 우측 상단 최종 저장은 공개 스냅샷을 적용한다. 초안 저장은 기존 공개 내용을 유지한다. 담당자 전환 시 미저장 내용 확인창을 제공하며 비동기 작업 중 전환·중복 저장을 잠근다.
- 사진 지정 옆 AI 이미지 보정 안내와 백재원 실장 오픈채팅 바로가기를 제공한다. 파일 선택 버튼은 키보드 접근 가능한 기본 파일 입력을 유지하면서 스타일을 적용한다.
- 프로필 사진을 브라우저에서 최대 1000px JPEG로 변환하며 메타데이터를 제거한다. 초기 버전은 사진을 명함 JSON에 보관한다.
- OG 메타태그는 서버 HTML에 포함된다. 공개 스냅샷 사진을 OG 이미지로 제공한다. 메신저의 기존 미리보기 캐시는 별도로 남을 수 있다.
- 전화번호로 카카오 개인 채팅을 강제로 열지 않는다. 선택적으로 등록한 `open.kakao.com` 또는 `pf.kakao.com` HTTPS 링크를 사용한다. 미등록 시 번호 복사·친구 추가 안내를 제공한다.
- 방문 집계는 동일 브라우저 30분 단위, 버튼 클릭은 10초 단위로 중복을 억제한다. 방문자 식별자는 카드별 해시로 저장하며 IP·전화번호는 이벤트에 저장하지 않는다.
- 방문 수에서 추정 방문자 수를 뺀 값을 추정 재방문 횟수로 표시한다. 브라우저 초기화/기기 변경에 따라 오차가 생긴다. 실제 상담/저장 완료 지표가 아니다.
- 크롤러의 HTML/OG 사진 요청 자체는 방문으로 집계하지 않는다. 미리보기도 집계하지 않는다.
- 공개 이벤트 API는 익명 서비스이므로 악의적인 브라우저 ID 변경에 의한 조작을 완전히 막지는 못한다. 운영 배포 전 레이트 제한·보관 기간 정책을 별도 결정한다.

## 로컬 확인

`npm.cmd run dev -- --host 127.0.0.1`

1. 로그인 후 전자명함에서 사용자 설정의 이름/전화 등 고정 정보를 확인하고 사진/문구 입력.
2. 미리보기 갱신 → 초안 저장 → 공개 내용 적용.
3. 공개 명함을 새 탭에서 열고 전화/카카오/연락처 저장 버튼 확인.
4. 관리 화면 새로고침으로 집계 확인. 다른 계정에서는 자신의 명함만 표시되어야 한다.
5. 비공개 전환 후 이전 주소와 사진/연락처 주소가 차단되는지 확인.

## 사용자 설정 동기화

### 고객에게 전달하기 / 저장 분리 검토

- 링크만 복사, 안내 문구+링크 복사를 별도로 제공한다. 문구의 이름/직책/링크 변수는 복사 시 치환된다.
- 안내 문구는 `business_card_messages`에 담당자별 저장한다. 별도 저장 버튼은 공개 상태나 명함 초안/이미지를 변경하지 않는다. 일반 담당자는 본인 것만, 마스터는 선택 담당자의 문구를 저장할 수 있다.
- 명함 삭제 시 해당 담당자의 안내 문구도 함께 삭제된다.
- `business_cards`(초안/공개본), `business_card_events`(통계), `business_card_short_links`(단축 주소), `business_card_messages`(전달 문구)는 분리되어 있다.
- **업로드 이미지는 이미지 전용 테이블로 분리되어 있지 않다.** 프로필/커스텀 이미지는 JPEG data URL로 명함 JSON 내부에 저장되며 초안/공개본에 중복될 수 있다. 기본 로고와 수수료 이미지는 `public/brand` 정적 파일이다. 이미지 전용 저장소 분리/마이그레이션은 이번 문구 기능 변경에 포함하지 않는다.

- 일반 담당자는 이름·부서/팀·직책·지점/본사·휴대전화를 수정할 수 없다. 마스터는 선택 담당자의 모든 명함 정보를 수정할 수 있다.
- 마스터의 변경값은 명함 JSON의 `identityOverrides`로 저장하며 사용자 설정 원본은 변경하지 않는다. 일반 담당자의 요청으로 이 값을 위조하거나 덮어쓸 수 없다.
- 지정값이 없는 필드는 최신 사용자 설정과 동기화한다. 초안과 공개본의 지정값을 분리하므로 초안 저장만으로 공개 정보가 바뀌지 않는다. 공개 적용 후 명함·전화 상담·VCF에 반영된다.
- 이메일만 가입 이메일을 초기값으로 사용하며 커스텀 값(빈 값 포함)은 유지한다.
- 휴대전화 표시는 `010.1234.5678`로 통일한다. 사용자 원본 DB 값은 변경하지 않는다.
- 이미지 보정 요청 버튼: https://open.kakao.com/o/s94BCITi

로컬 서버 주소는 외부 고객과 메신저 크롤러에서 접근할 수 없다. 운영 공개 주소는 `https://my-docs.kr/card/:slug`이다. 별도 마이그레이션은 `d1/migrate-business-cards.sql`이며 경로 최초 접근 시에도 테이블을 생성한다.

## 사용설명서

- 관리 화면 좌측 상단에서 `public/manuals/business-card-user-guide.pdf`를 다운로드한다.
- 생성 소스: `scripts/pdf/create_card_manual.py` (ReportLab 및 Windows 맑은 고딕 필요).
- `output/pdf`는 로컬 생성 산출물이며 배포용 PDF만 버전 관리한다.
- 문자 미리보기는 수신 앱에 따라 다르다. 실제 아이폰 테스트에서는 설명과 링크를 함께 전송하면 미리보기가 없었고 링크만 별도 전송하면 표시됐다. 모든 기기에 대한 표시 보장은 하지 않는다.
