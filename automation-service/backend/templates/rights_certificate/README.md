# 권리분석 보증서 템플릿 폴더

이 폴더의 `certificate.pptx` 파일이 권리분석 보증서 생성에 우선 사용됩니다.
`certificate.pptx`가 없으면 예비용 `certificate.html` 템플릿을 사용합니다.

템플릿 교체 시 같은 파일명으로 넣어주세요.

PPT 첫 페이지는 기존 보증서 폼을 그대로 사용합니다. 두 번째 페이지부터는 원본 두 번째 슬라이드의 배경·머리말·꼬리말 스타일을 복제한 사건별 서술 보고서를 넣고, 원본 네 번째 슬라이드 `낙찰 후 명도절차 안내`는 수정하지 않은 채 항상 마지막 페이지로 보존합니다. 서술 페이지마다 내용 길이에 따라 최대 4개 박스를 배치하며, 확인된 사실과 실제 쟁점·영향·입찰 전 조치를 문단 단위로 출력합니다. 사건에 존재하지 않는 `자료 미확보 및 추가 확인 범위`를 분량 채우기용으로 만들지 않으며, 실제로 결론에 영향을 주는 자료 공백이 있을 때만 해당 범위를 서술합니다. 내부 32항목 판정표와 규칙 출처는 고객 문서에 노출하지 않습니다.

자료 상태는 `확보(collected)`, `전체 수집 확인(complete)`, `수집 실패(failed)`를 분리합니다. 확보됐지만 전체성이 검증되지 않은 자료도 실제 확인된 기재와 날짜·권리종류는 상세 서술하되, 그 자료만으로 다른 권리나 특이사항이 없다고 단정하지 않습니다. 매각물건명세서는 모든 렌더링 페이지의 텍스트 확인과 핵심 구역(점유·비고·최선순위) 검증까지 성공하거나, 상위 수집기가 명시적으로 `source_completeness`를 전달한 경우에만 부재 판단 범위로 사용합니다. OCR 일부, 제목뿐인 PDF, 감정평가 요약문, 단순 권리행 존재는 확인된 사실의 근거일 뿐 전체성의 근거가 아닙니다.

서술 보고서는 잘림을 막기 위해 고정된 세로형 지면에 렌더링됩니다. 교체 템플릿의 슬라이드는 최소 **7.5 x 10.8인치**여야 하며(기본 템플릿은 7.5 x 10.83인치), 가로형 또는 이보다 작은 템플릿은 글자를 축소하지 않고 생성을 중단합니다. 본문은 10pt 이상이며, 문단 전체가 다음 페이지로 이동하므로 문단 중간이 나뉘지 않습니다.

- 폴더: `backend/templates/rights_certificate`
- PPT 템플릿: `certificate.pptx`
- 원본 샘플: `sample.pptx`
- 예비 HTML 템플릿: `certificate.html`
- 출력: `backend/output/권리분석_보증서_{task_id}.pdf`
- PDF 변환을 사용할 수 없는 PC에서는 `backend/output/권리분석_보증서_{task_id}.pptx`가 다운로드됩니다.

PPT 첫 페이지 주요 변수:

- `{{caseNumber}}`
- `{{caceNumber}}` (`caseNumber` 오타 호환)
- `{{court}}`
- `{{createdDate}}`
- `{{createDate}}` (`createdDate` 별칭)
- `{{authorName}}`
- `{{baseRightDescription}}`
- `{{tenantAnalysisText}}`
- `{{surplusDescription}}`

현재 주요 파싱 기준:

- 사건번호: `#header_detailz > h2 > strong > span`
- 법원: 상세 헤더와 기본정보 표를 기준으로 하며, 지원명만 확보된 경우 상위 지방법원까지 합쳐 `수원지방법원 안양지원`처럼 출력
- 말소기준권리: `건물 등기부현황`, `토지 등기부현황`, `등기부현황` 표와 문서 내용을 기준으로 구성. 근저당권 등 실체 권리만 건수·기재금액 합계에 포함하고, 경매개시결정 기입등기 및 신청채권은 절차 내역으로 분리하여 중복 합산하지 않음
- 임차내역: `#dtlw_link > ul > li:nth-child(5) > a` 또는 `매각물건명세서` 링크/탭을 통해 매각물건명세서 내용을 기준으로 구성
- 임차내역 출력 항목: 점유자 성명 / 점유구분 / 보증금 / 차임 / 전입일 / 확정일 / 배당요구일
- 법무법인 검토: 제목이 정확히 `법무법인 명승 권리분석`인 구역 내부 표만 수집하여 출처가 표시된 별도 서술 블록으로 출력

추가로 사용할 수 있는 공통 변수:

- `{{propertyType}}`
- `{{appraisalValue}}`
- `{{minBidPrice}}`
- `{{bidDate}}`
- `{{authorTitle}}`
- `{{authorPhone}}`
- `{{baseRightDate}}`
- `{{baseRightType}}`

HTML 예비 템플릿도 첫 페이지 이후 `{{narrativeReportHtml}}`에 같은 서술 보고서를 삽입합니다. 체크표, 담당자용 판정 근거, 원문 OCR 및 내부 규칙명은 출력하지 않습니다.
